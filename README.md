# Finance-Transactions-Analysis-PowerBI
Interactive Finance Transactions Analysis Dashboard developed using Microsoft Power BI to analyze financial KPIs, transaction trends, customer segmentation, state-wise performance, and year-over-year financial metrics.

# Finance Transactions Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing financial transactions using Microsoft Power BI. The dashboard provides insights into financial performance, transaction trends, customer demographics, and business performance through interactive visualizations.

## Project Objectives
- Monitor key financial performance indicators.
- Analyze transaction trends over different time periods.
- Understand customer segments and transaction behavior.
- Evaluate financial performance using Year-over-Year analysis.
- Explore transaction details and identify business patterns.

## Dashboard Pages

### 1. Overview Analysis
- Total Amount
- Total Transactions
- Average Transaction Amount
- Total Fees
- Total Tax
- Year-over-Year performance analysis
- Transaction trends over time
- Transaction status distribution
- Customer segment analysis
- State-wise transaction analysis
- Gender-wise transaction distribution
- Transaction type analysis

### 2. Transactions
- Detailed transaction records.
- Transaction ID and transaction date.
- Customer name and transaction type.
- Transaction status and customer demographics.
- Total amount, fees, and tax.
- Interactive filters for detailed analysis.

## Key Features
- Interactive KPI cards.
- Dynamic metric selection.
- Year and month filters.
- Occupation-based filtering.
- Merchant category filtering.
- Interactive visualizations and report navigation.

## How to Use
1. Download the PBIX file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Navigate between Overview Analysis and Transactions.
4. Explore the dashboard using interactive filters.
